# McServerManager 1.2.0 +「容器搬运工」0.2.1

本体版本号保持 1.2.0 不变（已在发行版里发布过），本包是**「本体 1.2.0 + 官方插件容器搬运工 0.2.1」的组合发行版**：
把一台服务器连同它的容器打包成一个 `.tar`，换台机器再导入回来，服务器直接进列表。
为支持插件的交互操作，这个包里的管理器额外带了「可勾选表格 + 原生文件对话框」的插件 SDK 扩展。

## 下载

| 文件 | 说明 |
| --- | --- |
| `McServerManager-1.2.0-win64-with-container-porter.zip` | Windows 10/11 64 位便携版，**自带容器搬运工插件**（不需要安装 Qt 或 Java） |
| `plugin-packages/com.mcsm.container-porter-0.2.1.zip` | 插件单独安装包（包内已附，也可单独分发） |
| `docs/PLUGIN-SDK.md` | 插件接口文档 |

> 使用前请先安装并启动 [Docker Desktop](https://www.docker.com/products/docker-desktop/)。
> 数据目录仍是 `%LOCALAPPDATA%\McServerManager`，覆盖解压即可升级。

## 插件「容器搬运工」0.2.1

安装并启用后，左侧导航多出「导入与导出」页面：

* **勾选服务器**：表格每行前面有勾选框，右上角有「全选 / 全不选」，
  「当前选中服务器」一行显示已选中的服务器（超过三台显示成「A、B、C 等 N 台」）与数量。
* **导出前先选位置**：勾选一台时弹出「另存为」，可以直接改名；勾选多台时弹出「选择文件夹」，
  每台各生成一个包。取消对话框不会导出任何东西。
* **三种导出粒度**：数据 + 配置 / 含容器镜像（`docker commit` + `docker save`）/ 完整（再加备份与日志）。
* **导入**：点「选择容器包导入…」挑一个 `.tar`，管理器会解开它、分配空闲的 id 与端口、
  必要时改写 `server.properties`，并把服务器**直接加入服务器列表**（几秒内刷新出来）。

容器包内部是 `manifest.json` + `data.tar` + 可选 `image.tar`，可以当普通文件复制、上传网盘。

版本沿革：0.1.0 首次发布（导出/导入）→ 0.2.0 多选导出与先选路径、选文件导入 →
0.2.1 修复勾选框被裁与左侧留白。

## 插件 SDK 扩展

* `table` 区块新增 `selectable` / `key` / `rowIds` / `selected`，勾选变化通过 `ui.selection` 事件通知插件。
* `buttons` 新增 `action`（点击回调脚本，配 `mcsm.ui.onAction`）与 `pick`
  （`save` / `open` / `dir` / `auto`，管理器先弹原生对话框，再把路径交给回调）。

## 修复

* 插件页表格的表头与内容不对齐：表头改为左对齐，并给表头与单元格统一内边距。
* 插件页表格的勾选框右侧被裁、左侧留白过大：勾选框列改为固定列宽，文本内边距改由 delegate 绘制
  （QSS 的 `item` padding 会连 cell widget 一起内缩）。

## 兼容性

* 版本号仍是 1.2.0，数据目录、`servers.json` 与插件包格式均未变化，可直接覆盖升级。
* 插件声明 `minManagerVersion: 1.2.0`；但「可勾选表格 / 原生对话框」是本包才有的 SDK 扩展，
  早先发布的 1.2.0 原生包没有这些接口，请用本组合包（或更新后的构建）。
* 插件 SDK 为**增量**扩展：已有的 apiVersion 1 插件不需要修改。
