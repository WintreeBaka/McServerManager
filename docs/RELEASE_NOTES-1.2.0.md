# McServerManager 1.2.0

1.2.0 调整了「切换服务器」和「退出」时的交互，并修复了启停服务器时重复弹窗的问题。

## 下载

| 文件 | 说明 |
| --- | --- |
| `McServerManager-1.2.0-win64.zip` | Windows 10/11 64 位**含 GUI 的便携版**（不需要安装 Qt 或 Java） |
| `McServerManager-1.2.0-win64-cli.zip` | **纯 CLI 精简版**（约 6.5 MB，只有 mcsm-cli.exe 与 Qt Core/Network，适合脚本/服务器/无桌面环境） |
| `PLUGIN-SDK.md` | 插件接口文档（单独附件，也随包放在 `docs/`） |
| `com.mcsm.player-admin-1.0.0.zip` | 官方插件「玩家管理」安装包 |

> 使用前请先安装并启动 [Docker Desktop](https://www.docker.com/products/docker-desktop/)。
> 两个包共用同一数据目录（`%LOCALAPPDATA%\McServerManager`），可以只下载其中一个。

## 新功能

### 切换服务器不再弹确认框

以前只要配置页有未保存的修改，切换到别的服务器就会弹「未保存的修改…继续吗？」，
一次普通切换被硬生生打断。现在：

* 切换服务器**不再弹窗**，直接载入目标服务器的配置；
* 服务器名称末尾会出现 `*`，表示这台服务器的配置**与最近一次配置备份不一致，或者还没有备份**。
  标记会同时出现在「服务器」页的列表、顶栏的服务器选择器、以及服务器详情标题上；
* 保存配置（会自动生成备份）或回滚之后，星号自动消失。

### 退出时提示仍在运行的服务器

关闭管理器时，如果还有服务器在运行，会列出服务器名称并提示：

> 退出管理器不会关闭它们，服务器会继续在容器中运行。

可以选择「取消」留在程序里，或确认退出——正在运行的容器不受影响。

## 修复

* **启停服务器时重复弹窗**：启动或停止一台服务器后，顶栏的服务器选择器在列表刷新时
  会无条件发出「服务器已切换」，导致配置页被重新加载并触发未保存提示，一次启停最多弹两次。
  现在只有选中项真的变化时才发出信号。
* 后端 `server list` / `server get` 新增 `configPending` 字段（当前配置是否领先于最近的备份），
  界面直接使用，不需要为每台服务器额外发请求。

## 升级说明

* 直接覆盖解压到原目录即可，数据目录、已创建的服务器和配置备份都不受影响。
* 插件接口（apiVersion 1）没有变化，已安装的管理器插件可以继续使用。
