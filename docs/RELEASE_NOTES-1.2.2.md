# McServerManager 1.2.2

1.2.2 是审计修复计划 v1 的应急止血版本，集中收口插件、导入包、URL 与配置边界。

## 安全修复

* 插件设置只能写入自身数据前缀，不能再改写后端可执行路径等全局设置。
* 自定义后端路径必须由用户显式确认；便携版始终优先使用同级 `mcsm-cli`。
* 容器包导入增加成员路径、链接类型、大小配额和解压后真实路径检查。
* 插件 `dockerArgs` 禁止特权模式、卷挂载和 host 网络。
* 插件外链只允许 http/https，RichText 链接与插件 URL 导入不再绕过协议检查。
* `levelName`、`motd` 和字体族增加注入过滤。

## 其他修复

* 插件事件 / 动作处理使用处理器快照，消除同步修改列表导致的失效风险。
* 插件安装前明确提示完整本机权限；`permissions` 仍然只是说明字段。
* EULA 默认不自动同意，RCON 密码使用系统 CSPRNG。
* 容器启动脚本加固 `jarName`，配置快照 ID 增加毫秒精度，删除未使用代码。

## 升级说明

* 直接覆盖解压到原目录即可，数据目录、服务器记录和配置备份不受影响。
* 插件接口（apiVersion 1）没有变化。
* 本版本只覆盖修复计划 v1；信任链、脱敏和权限强制模型仍留待后续版本。
