# McServerManager 1.1.4

1.1.4 是一个**界面缺陷修复版**：修复了通知条被裁切 / 重复显示、配置与备份页“刷新”无反馈、
配置备份行按钮被裁掉下半截等问题。无接口、协议与数据格式变更，可直接覆盖升级。

## 下载

| 文件 | 说明 |
| --- | --- |
| `McServerManager-1.1.4-win64.zip` | Windows 10/11 64 位**含 GUI 的便携版**（不需要安装 Qt 或 Java） |
| `McServerManager-1.1.4-win64-cli.zip` | **纯 CLI 精简版**（约 6.5 MB，只有 mcsm-cli.exe 与 Qt Core/Network，适合脚本/服务器/无桌面环境） |
| `PLUGIN-SDK.md` | 插件接口文档（单独附件，也随包放在 `docs/`） |
| `com.mcsm.player-admin-1.0.0.zip` | 官方插件「玩家管理」安装包 |

> 使用前请先安装并启动 [Docker Desktop](https://www.docker.com/products/docker-desktop/)。
> 两个包共用同一数据目录（`%LOCALAPPDATA%\McServerManager`），可以只下载其中一个。

## 通知（Toast）

| 现象 | 原因 | 1.1.4 行为 |
| --- | --- | --- |
| 通知右侧被窗口边缘切掉 | 长中文没有断行位置，标签把卡片撑得比 320px 通知条更宽；且通知条不跟随窗口缩放 | 文本改为在卡片内换行，通知条随窗口尺寸重新贴回右上角 |
| 同时触发两条通知却显示成三条 | 卡片位置由“位移动画”和布局同时管理，两条通知被动画到同一个位置而重叠 | 位置完全交给布局，入场/退场只做淡入淡出；同一条消息 700ms 内重复到达会合并 |

## 主题切换

切换亮色 / 暗色主题后，标题栏左上角的「后端就绪」「Docker 未运行」两个状态胶囊、
窗口按钮与图标会立即换成新配色，不再需要重启才正确渲染。
（这些控件把颜色写在行内样式表里，原来只在状态变化时才重刷。）

切换「色彩风格」时只会弹出一条通知：主题与色彩两个分段控件在内部同步时曾走到
`currentChanged`，被误当成一次用户操作，额外弹出一条「已切换到××主题」。

标题栏副标题 `Docker 化运行环境 · 一键配置` 不再折行——原来它被挤成两行，
第二行会被固定高度的标题栏裁掉。

## 配置 / 备份页

* 「配置备份」和「备份列表」的**刷新按钮现在有反馈**：点击先显示“正在刷新…”，
  完成后显示条数；未选择服务器或刷新失败都会提示，不再静默无响应。
* 配置备份行的**「回滚到此版本」按钮不再被裁掉下半截**：行高按该行实际宽度重新测量
  （备注会换行），并补回列表条目 padding 占用的高度；列表宽度或窗口尺寸变化时都会重排。
* 备份页进入时先同步当前服务器 ID，避免刷新应答被“服务器已切换”的判断丢弃。
* 「关于」卡片显示程序真实版本号，不再硬编码 1.0.0。

## 升级说明

* 直接覆盖解压到原目录即可，数据目录与已创建的服务器不受影响。
* 无需重新安装 Docker 镜像，无需迁移 `servers.json` 或插件注册表。
