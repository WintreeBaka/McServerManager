# McServerManager 1.2.3

1.2.3 是审计修复计划 v2，主题为信任链、凭据最小化和备份/下载完整性。

## 安全修复

* 容器搬运工导入只接受服务器记录白名单字段，主机 JDK 运行时和非本机镜像必须二次确认。
* 容器包默认不导出原 RCON 密码，导入时生成新密码。
* CLI 状态输出与插件钩子负载不再携带 RCON 密码；player-admin 改用受控命令行通道。
* `servers.json` 权限收窄到当前用户。
* 备份删除和恢复拒绝绝对路径、`..`、符号链接、硬链接及未授权归档名。
* HTTP 请求强制 HTTPS（本机回环例外），限制响应大小并校验 Mojang、Paper、Modrinth 哈希。

## 工具链与修复

* 内置 7-Zip 升级到官方 26.06 x64，并加入 SHA-256 校验、打包前检查和 CI 校验。
* 修正备份成功判定、陈旧 porter 临时目录、`~` 方法参数、插件错误堆栈外泄等问题。

## 升级说明

* 直接覆盖解压到原目录即可，服务器记录和存档保持兼容。
* 旧的 player-admin 插件请升级到 1.1.0；容器搬运工请升级到 1.1.0。
* `apiVersion` 仍为 1。
