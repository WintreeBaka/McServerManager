# McServerManager 1.2.4

1.2.4 是修复计划 v3 的健壮性收尾版本，同时补充了面向贡献者的完整开发文档。

## 稳定性与进程安全

* 插件异步后端回调统一经过脚本看门狗与隔离机制，插件异常不会绕过执行预算。
* `servers.json` 的读取、修改和写回在同一进程锁与文件锁内完成；插件导入服务器时
  通过受控 `server register` 注册，避免并发写入丢失记录。
* 服务器和插件服务进程增加 PID 复用校验、映像与命令行核对；超时清理在 POSIX 上
  使用进程组，不再无条件依赖 Windows `taskkill`。
* 修正 RCON 响应包读取，避免把认证残留包误当成命令结果。

## 前端与插件

* 插件页面、日志视图和流式输出增加明确的大小与数量上限，并通过防抖减少重复重绘。
* 请求看门狗不再同步阻塞界面；流启动失败会正确释放进程对象。
* 服务端类型、插件列表和服务器详情加载失败时会在界面中显示错误，而不是静默空白。
* player-admin 在线模式在 Mojang UUID 解析失败时直接报错；越出 `servers` 根目录的
  路径会被拒绝；运行中且 RCON 不可用时不会直接改写玩家文件。

## 工具链、CI 与发布

* GitHub Actions 使用只读权限、固定提交 SHA、匹配的 MinGW，并让后端冒烟测试阻塞构建。
* 构建和测试脚本自动发现 Qt，不再依赖固定盘符；递归清理必须具备托管标记并通过
  根目录与敏感路径检查。
* 发布包包含 SHA-256 文件与 LGPL-3.0 全文；Gitea 发布通过认证头上传，不会把令牌
  放入 `curl` 命令行参数。
* Windows 构建启用编译器与链接器加固，应用版本统一从 CMake 读取。

## 升级说明

* 可直接覆盖安装 1.2.3；服务器记录、配置备份、世界备份和插件数据保持兼容。
* 插件接口 `apiVersion` 仍为 1，官方插件最低管理器版本仍为 1.2.3。
* 1.2.4 只做健壮性与文档更新，不改变服务器数据的存储格式。
