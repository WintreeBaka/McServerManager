# McServerManager 1.3.1

1.3.1 是界面稳定性更新，保留 1.3.0 的管理器插件 API 2 权限模型。

## 修复

* 亮色主题下，插件导入、权限管理和其它顶层对话框不再错误显示深色背景。
* 次级蓝色操作按钮使用统一的填充、描边与悬停亮度；危险操作仍保持独立强调色。
* 设置页动画速度滑杆的右手柄和轨道不再被裁切。

## 动效与资源

* 通知弹出、堆叠上移和消失均使用布局友好的高度与透明度动画，不移动通知到窗口外。
* 桌面端使用正式 SVG 应用图标，GUI 发行包会携带同一图标资源。
* README 的界面截图更新为 1.3.1 当前界面。

## 兼容性

* 管理器插件继续要求 `apiVersion: 2`；API 1 插件仍会显示为不兼容并阻止执行。
* 安装与升级检测、SHA256 文件和发行包目录结构保持不变。
